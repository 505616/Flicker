`D:\新项目` 已不存在，仓库里对旧路径的举例引用也早已全部改成 `D:\闪传`。
唯一还留着旧路径的是 `_lab/out/*.log` 这类**历史日志**和一次性脚本

改名后基线复验过（本轮）：`npm test` → **637 用例 / 633 通过 / 4 跳过 / 0 失败**，
`npm run check` → 全过（24 条判据）。**改名不影响任何东西**：项目里没有硬编码的工作区绝对路径。

> **改名是怎么做成的**（下次遇到同类问题照这个来）：
> Windows 不允许改名"任何进程的当前目录所落在的那个文件夹"，而当时那正是 DSH 服务进程
> （它托管着对话），所以 `Rename-Item` 直接被拒（`Access to the path 'D:\新项目' is denied.`）。
> 换一个目录去敲命令没用 —— 卡住的是那个**服务进程**，不是 shell。
> 诊断方法：`Rename-Item D:\<目录>\_某个子目录 _probe` —— 子目录能改、根目录不能改，
> 就说明"有进程的当前目录在这个根目录上"。
> 解法：**关掉 DSH** → 在别的目录里 `Rename-Item -LiteralPath 'D:\新项目' -NewName '闪传'`
> → `cd D:\闪传` 重新启动 DSH，并把新对话的工作区设成 `D:\闪传`。

## 一、这个项目是什么（一句话版本）

**闪传 Flicker**：两台电脑输入同一个密码才能传文件，**接收端零安装**（对方只要浏览器打开链接），
**所有传输用到的东西用完即销毁**（密钥清零、服务关闭、链接失效、证书移除）。
零运行时依赖（只用 Node 内置模块），可打包成单文件 exe（约 94 MB）。

三条传输通路，都在用同一套密码学：

| 通路 | 命令 | 场景 |
|---|---|---|
| 局域网直连 | `flicker send <路径>` | 同一个 WiFi/路由器下，最常用 |
| 中继（跨网络） | `flicker send <路径> --relay=<地址>` | 两边不在同一个网络（需要自己部署一次中继） |
| **接收模式（反向）** | `flicker recv` | **手机把照片/视频发给电脑**（手机只开浏览器，不装东西） |

图形界面：`flicker`（不带参数）→ 本地网页 `http://127.0.0.1:<随机端口>/`，
首页既能发文件，也有「接收文件」入口。

## 三、这个项目的"规矩"（不是风格偏好，是踩出来的）

如果你的做法和下面某条冲突，**先读那一条背后的故事**（都写在注释或文档里），再决定要不要破例。

1. **判据必须能被证伪。** 每条测试/检查都要能说出"它失败时是什么样"。项目里反复出现的做法是：
   写一个 `_lab/verify-*.mjs` 或一条用例，**故意做错**，证明判据真的会拦。
   例：`gen/check-doc-flags.mjs` 塞一个假参数、`gen/check-pack-pii.mjs` 塞一个带邮箱的文件、
   `gen/check-test-cleanup.mjs` 塞一段坏写法 —— 都验过会失败。
2. **失败不许被说成成功。** 这是本项目的第 0 条。删不掉就报失败、没收到就说没收到、
   测量脚本不确定就写"未验证"。**"看起来对"是最危险的中间态。**
3. **测试跑的那条路必须是用户默认走的那条路。** 曾因"所有中继用例都带 `--no-gift`，
   而赠品默认开着"漏掉一个 100% 复现的 bug（清单 4.97 MB 超限）。
4. **两份实现一定会漂移。** 密码学有两份（Node `src/suite/flicker1.js` + 页面 WebCrypto），
   手机页是第三份 —— 它们之间由**逐字节比对**的测试钉住（`test/phone-page.test.js`）。
   加第四份之前请先想清楚；能内联共用就共用（`gen/inline-*.mjs`）。
5. **文档必须是真的。** 有 24 条机器判据在守：中英配对与结构、文档里的链接、
   文档里的参数 vs CLI、协议文档字段 vs 实现（§6.1 与 §7R 各一条）、插件事件表、
   赠品个人信息、临时目录前缀、**CI 与 `npm run check` 是否跑同一批命令**…
   改文档前先跑 `npm run check`，它会告诉你哪里会漂。
6. **不留痕迹。** 程序用完的密钥/证书/临时目录要清干净；**测试工具也一样**
   （临时目录走 `gen/tmp.mjs` 的 `makeTempDir()`，否则判据会拒）。
7. **零依赖。** `dependencies` 必须是空的（`gen/check-no-deps.mjs` 在守）。
   需要什么就用 Node 内置模块自己写 —— 包括 X.509 编码、二维码、SHA-256、CDP 客户端。
8. **不要自动化有窗口的东西。** 测试/演练一律 headless；不要弹浏览器、**不要弹资源管理器**
   （`FLICKER_NO_OPEN=1` + `--no-open` 是两道保险）。曾因测试跑完删掉临时目录、
   而窗口还开着，弹出"位置不可用"的系统错误框糊在用户脸上。

   "Windows 的证书安装之前都是我点的"），CI 上没人点就一直等。处理：

     所以那 4 条从来没被真跳过；在 Linux 上只是靠"整个文件被排除"才没炸。

   **CI / macOS**：产物一直起不来，分两次查清：
