## The original request

I want to make a file transfer program

This program can transfer my files to other computers. The target computer does not need to download the program; only the computer starting the transfer needs it. You can choose the files to send and then set a password, and both computers must enter the same password before anything is transferred. Of course the two computers have to be connected to each other first. Everything used for the transfer is one-shot and is destroyed once it is used up.

The above is the original request I gave DeepSeek
